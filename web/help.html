{{i:rocket:lg}}Démarrer en 3 étapes

Les deux appareils doivent être sur le même Wi‑Fi (ou le même réseau filaire).

1

Sur le PC

Lance start.bat (ou python lanshare_rtc.py), puis clique sur « Partager mon écran ».

2

Sur l'autre appareil

Ouvre l'adresse affichée (ex. http://192.168.1.20:8080) ou scanne le QR code.

3

Entre le PIN

Tape le code à 4 chiffres. Avec le QR code ou le lien direct, il est déjà saisi.

{{i:wrench:lg}}Dépannage

Clique sur ton symptôme.

{{i:wifi-off:l}}L'autre appareil n'arrive pas à ouvrir l'adresse{{i:chevron-down:ch}}
  • Même réseau ? Les deux appareils sur la même box ou le même Wi‑Fi. Pas un en 4G, pas un sur le « Wi‑Fi invité ».
  • Isolation des clients (« AP isolation », fréquente sur les Wi‑Fi invités, hôtels, écoles) : elle bloque la communication entre appareils. Change de réseau ou utilise le partage de connexion d'un téléphone.
  • VPN actif sur le PC ? Coupe‑le le temps du partage.
  • Pare‑feu : voir la section dédiée plus bas.
  • Vérifie que tu tapes http:// (pas https) et le bon port.
{{i:monitor:l}}La page s'ouvre mais l'image reste noire ou « Connexion au PC… »{{i:chevron-down:ch}}
  • Le partage est‑il toujours actif sur le PC ? Ne ferme pas l'onglet LanShare.
  • Le pare‑feu bloque la vidéo (UDP) même si la page s'ouvre : autorise Python ou le navigateur sur le réseau privé.
  • Attends 5 secondes, puis recharge la page du spectateur.
  • Teste avec le mode démo : s'il fonctionne, le problème vient de la capture d'écran, pas du réseau.
{{i:monitor-up:l}}Le bouton « Partager mon écran » ne fait rien ou affiche une erreur{{i:chevron-down:ch}}
  • La page de partage doit être ouverte via http://localhost:…/share sur le PC lui‑même (pas via l'adresse IP).
  • Utilise Chrome, Edge ou Firefox récents. Sous macOS, autorise l'enregistrement d'écran : Réglages Système › Confidentialité et sécurité.
  • « Partage annulé » : la fenêtre de sélection a été fermée, clique à nouveau.
{{i:volume-x:l}}Pas de son{{i:chevron-down:ch}}
  • Le son système n'est partagé que par Chrome / Edge sous Windows : choisis « Écran entier » et coche « Partager le son du système ».
  • Sous macOS et Linux, seul le son d'un onglet peut être partagé.
  • Côté spectateur, clique sur « Activer le son » (ou touche M) : les navigateurs bloquent le son automatique.
{{i:gauge:l}}L'image est saccadée, floue ou en retard{{i:chevron-down:ch}}
  • Mets le spectateur en Wi‑Fi 5 GHz ou en câble, et rapproche‑le de la box.
  • Texte flou ? Choisis « Texte et documents ». Saccades ? Choisis « Vidéo et jeux » (relance le partage après changement).
  • Partage une fenêtre plutôt que tout un écran 4K et ferme les applications lourdes.
  • Plusieurs spectateurs demandent plus de puissance au PC : limite‑les si besoin.
{{i:key-round:l}}J'ai oublié le PIN{{i:chevron-down:ch}}

Il est affiché dans le bandeau en haut de la page de partage et dans le terminal. Tu peux aussi le fixer au lancement : python lanshare_rtc.py --pin 1234. Après 5 erreurs, patiente 30 secondes.

{{i:plug:l}}Le port 8080 est déjà utilisé{{i:chevron-down:ch}}

LanShare choisit automatiquement le port libre suivant et l'affiche. Pour imposer un port : python lanshare_rtc.py --port 9000.

{{i:brick-wall:lg}}Pare‑feu

À faire une seule fois sur le PC qui partage.

{{i:monitor:l}}Windows{{i:chevron-down:ch}}

Au premier lancement, Windows demande l'accès réseau pour Python : coche « Réseaux privés » puis Autoriser. Si tu as cliqué sur « Annuler » :

Paramètres › Réseau et Internet › Pare‑feu Windows Defender › « Autoriser une application » › coche Python (réseau privé).

Vérifie aussi que le réseau est de type Privé (Paramètres › Wi‑Fi › ta connexion › Type de profil réseau).

{{i:laptop:l}}macOS{{i:chevron-down:ch}}

Réglages Système › Réseau › Pare‑feu : autorise les connexions entrantes pour Python, ou désactive le pare‑feu le temps du partage.

{{i:terminal:l}}Linux{{i:chevron-down:ch}}

Avec ufw, autorise le port et le trafic WebRTC local (remplace 192.168.1.0/24 par ton réseau) :

sudo ufw allow from 192.168.1.0/24 to any port 8080 proto tcp
sudo ufw allow from 192.168.1.0/24 to any proto udp

{{i:circle-help:lg}}Questions fréquentes

 

{{i:cloud-off:l}}Est‑ce que ça passe par Internet ?{{i:chevron-down:ch}}

Non. La vidéo va directement du PC vers l'autre appareil (WebRTC pair‑à‑pair), sans serveur externe ni compte. Tu peux même couper Internet.

{{i:shield-check:l}}Est‑ce sécurisé ?{{i:chevron-down:ch}}

Le flux WebRTC est chiffré. L'accès est protégé par un PIN, et seul le PC lui‑même peut lancer un partage. N'utilise pas --no-pin sur un réseau public.

{{i:smartphone:l}}Ça marche sur une TV, un iPhone, une tablette ?{{i:chevron-down:ch}}

Oui si l'appareil a un navigateur moderne : Chrome, Edge, Firefox, Safari (iPhone, iPad, Mac), navigateur d'une Smart TV récente ou d'Android TV.

{{i:users:l}}Combien de spectateurs ?{{i:chevron-down:ch}}

Plusieurs en même temps. Chacun reçoit son propre flux : 2 à 4 est un bon maximum selon la puissance du PC et du Wi‑Fi.

{{i:monitor-up:l}}Puis‑je partager depuis un téléphone ?{{i:chevron-down:ch}}

Pas pour l'instant : le partage se lance depuis le PC où tourne LanShare. Le téléphone sert de spectateur.

{{i:square:l}}Comment arrêter ?{{i:chevron-down:ch}}

Clique sur « Arrêter le partage », ou ferme le terminal (Ctrl+C). Les spectateurs repassent automatiquement en attente.

Toujours bloqué ?

Relance le diagnostic : il indique la cause la plus probable.
